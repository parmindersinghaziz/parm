# Dr. Parminder Singh 'Aziz' — Official Website

This repository hosts the personal and literary website of **Dr. Parminder Singh 'Aziz'** – an academic, poet, and review panelist writing in English, Punjabi, and Urdu.

The site presents his biography, accomplishments, literary works, publications, reviews, and contact details, complete with rotating Punjabi couplets and a clean literary design.

🔗 **Live site** : [https://parmindersinghaziz.com](https://parmindersinghaziz.com)

---

## ✨ Features

- **Rotating Punjabi couplets** with fade‑in/fade‑out animation
- **Responsive layout** that works on phones, tablets, and desktops
- **Clear navigation** with dropdown sections (About, Accomplishments, Literary Canvas, etc.)
- **Custom domain** hosted on GitHub Pages with auto HTTPS
- **Signature avatar** in a circular photo frame
